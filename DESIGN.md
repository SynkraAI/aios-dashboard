# CDM Portal — Design System

> Baseline design documentation for the AIOS Platform Dashboard.
> Generated by Uma (UX Design Expert) on 2026-05-06 from the live `aiox-dashboard` codebase.

This document describes the **as-is** design system. It is descriptive, not aspirational. Discrepancies between this doc and the running app are bugs in the doc — fix here first.

---

## Architecture

Three-tier token system, enforced via `@import` chain in `src/styles/tokens/index.css`:

```
primitives  →  semantic  →  component
   raw           intent       slot
   #D1FF00       --color-accent  --button-primary-text
```

Themes are **token-variable overrides**, not component rewrites. The default theme is **Liquid Glass** (warm light + dark via `.dark`). `data-theme="aiox"` swaps in the **AIOX Cockpit** theme by reassigning ~250 CSS variables.

| Layer | File(s) | Purpose |
|---|---|---|
| Primitives | `src/styles/tokens/primitives/{colors,spacing,typography,timing,sizing}.css` | Raw hex / px / rem values. Single source of truth. No semantics. |
| Semantic | `src/styles/tokens/semantic/{colors,glass}.css` | Intent (`--color-accent`, `--color-text-primary`, `--glass-shadow-default`). |
| Component | `src/styles/tokens/component/{button,input,toast,badge,progress,status-dot,sidebar,loader,radius}.css` | Component slots (`--button-primary-text`, `--input-focus-ring`). |
| Themes | `src/styles/tokens/themes/{dark,glass,matrix,aiox*}.css` | Variable overrides per theme. |
| Glass classes | `src/styles/liquid-glass.css` | `.glass`, `.glass-card`, `.glass-button-*`, `.glass-input` — consume tokens. |

### Squad colors (11 squads, gradient pairs)

Default theme uses tailwind-like vivid palette (purple/blue/orange/pink/green/cyan/teal/red/indigo/yellow/gray). AIOX Cockpit collapses all to a **lime → blue → flare → gray** brandbook hierarchy where:
- Lime family (orchestrator, design, dev) = primary doer roles
- Blue family (development, engineering, analytics) = build/data roles
- Flare family (content, creator, marketing) = creative roles
- Gray family (copywriting, advisory, default) = support roles

## Typography

### Default theme

```
--font-family-sans:    -apple-system, "SF Pro Display", "Segoe UI", Roboto, ...
--font-family-mono:    "SF Mono", "Fira Code", "Cascadia Code", Consolas, ...
--font-family-display: var(--font-family-sans)   (no display face — uses sans)
```

### AIOX Cockpit theme

```
--font-family-display: 'TASAOrbiterDisplay', system-ui, sans-serif   (headings, KPI values)
--font-family-sans:    'Geist', system-ui, sans-serif                (body)
--font-family-mono:    'Roboto Mono', 'SF Mono', monospace           (labels, code, terminals)
```

Fonts loaded via `src/styles/fonts/aiox-fonts.css` (TASAOrbiter via `packages/aiox-brandbook/`, Geist via npm `geist`, Roboto Mono via Google Fonts or local).

### Weights

`thin: 300 | regular: 400 | medium: 500 | semibold: 600 | bold: 700 | extrabold: 800 | black: 900`

### Sizes

| Token | Value | Notes |
|---|---|---|
| `--font-size-xs` | 0.625rem (10px) | Tight labels |
| `--font-size-sm` | 0.75rem (12px) | Secondary body |
| `--font-size-md` | 0.8125rem (13px) | Compact body |
| `--font-size-base` | 0.875rem (14px) | Body |
| `--font-size-lg` | 1rem (16px) | Emphasized body |
| `--font-size-xl` | 1.5rem (24px) | Section heading |
| `--font-size-2xl` | 2.5rem (40px) | Page heading |
| `--font-size-display` | 4rem (64px) | Hero / KPI values |

### Letter spacing

```
tight:   -0.03em  (display headings)
wide:     0.05em  (small caps labels)
wider:    0.08em  (cockpit labels — UPPERCASE)
widest:   0.12em  (hero / hazard labels)
```

### Cockpit typography rules

- Display headings: `TASAOrbiterDisplay`, `letter-spacing: -0.03em`.
- Labels: `Roboto Mono`, `text-transform: uppercase`, `letter-spacing: 0.08em`.
- Body: `Geist`, regular weight, no transform.

## Spacing

Two scales coexist — historical and brandbook.

### Historical (Tailwind-ish, in `primitives/spacing.css`)
```
--spacing-1: 0.25rem (4px)
--spacing-2: 0.5rem  (8px)
--spacing-3: 0.75rem (12px)
--spacing-4: 1rem    (16px)
```

### Brandbook 14-step scale (canonical going forward)
```
--space-0:  0px
--space-1:  4px
--space-2:  8px
--space-3:  12px
--space-4:  15px      ← brandbook "base" (NOT 16px)
--space-5:  20px
--space-6:  30px
--space-7:  40px
--space-8:  60px
--space-9:  80px
--space-10: 90px
--space-11: 120px
--space-12: 150px
--space-13: 180px
```

Tailwind exposes the brandbook scale as `bb-0` ... `bb-13` (e.g., `p-bb-4`, `gap-bb-6`).

## Radius

Component-tier (`component/radius.css`):
```
--radius-xs / --radius-sm / --radius-md / --radius-lg
```

Tailwind also exposes `rounded-glass` (1.25rem) and `rounded-glass-lg` (1.5rem).

**AIOX Cockpit overrides all radii to 0** — brutalist, no rounded corners on cockpit components. Default Liquid Glass uses generous rounding (12–24px).

Defined in `semantic/glass.css`, themed per palette:

## Transitions / Motion

```
--duration-fast:   ~120ms
--duration-base:   ~200ms
--duration-slow:   ~320ms
--duration-slower: ~480ms

--easing-default:  cubic-bezier(0.25, 0.1, 0.25, 1)   (smooth)
--easing-spring:   cubic-bezier(0.16, 1, 0.3, 1)      (decel + slight bounce)
--bb-ease-decel:   cubic-bezier(0, 0, 0.2, 1)
```

Cockpit-specific keyframes (in `aiox-animations.css`): `aiox-spin`, `aiox-pulse`, `aiox-ticker`, `aioxGlitchReveal`, `aioxLogoDissolve`, `aioxMorphSquare`, `aioxSpeedLinesDraw`, `aioxDropdownIn`, `aioxScanlineFade`.

Reduced motion: respected globally via `@media (prefers-reduced-motion: reduce)` block in `aiox.css` — animations capped to 0.01ms.

## Conventions

- **Class merging:** `cn()` helper from `src/lib/utils` (clsx + tailwind-merge).
- **Icons:** `lucide-react` (`^0.575.0`). Verify before invent.
- **State:** Zustand stores in `src/stores/` (e.g., `uiStore`). React Query for server state.
- **Routing:** internal hook `useUrlSync` (no react-router).
- **Code splitting:** every top-level workspace lazy-loaded via `React.lazy`.
- **Testing:** Vitest + React Testing Library + vitest-axe (a11y) + Playwright (E2E).
- **Storybook:** v10, with `addon-a11y`, `addon-vitest`, `addon-docs`. Required for every UI primitive.

## Known Issues (see `docs/design/AUDIT-BASELINE.md`)

Top issues at baseline:
1. Two parallel spacing scales (`--spacing-*` vs `--space-*`) coexist; usage is mixed.
2. Default theme `--font-family-display` aliases to `--font-family-sans` (no actual display face) — only AIOX theme uses TASAOrbiter.
3. Tailwind utility colors (`bg-blue-500`, `text-purple-600`) are still used in some components, requiring large remap blocks (Tier 5b in `aiox.css`).
4. Two distinct `kanban-priority-medium` / `-high` color values between default (`#60a5fa` / `#fb923c`) and AIOX (`#858585` / `#D1FF00`) — inconsistent semantics.
5. Liquid Glass default theme has no light/dark token bridge — `.dark` overrides are scattered.
6. Squad palette in default theme uses 11 distinct hues; AIOX collapses to 4 families. Documentation does not capture this collapse rule for new squads.
